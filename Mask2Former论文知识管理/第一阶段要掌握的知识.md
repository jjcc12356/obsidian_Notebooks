## 张量形态：
==**看到任意张量形态时，能够立刻说出每个数字代表什么，并判断它能不能送进Mask2Former**==
### python知识
- `变量.shape`：查看形状
- `变量.ndim`：查看维度数量
- Python下标从 `0` 开始
### 张量 Tensor
装着大量数字的多维容器
不同维度可以这样理解：

|类型|示例|维度数|
|---|---|---|
|一个数字|`5`|0维|
|一排数字|`[1, 2, 3]`|1维|
|一张数字表|`[[1,2],[3,4]]`|2维|
|一张多通道影像|`[C,H,W]`|3维|
|一批多通道影像|`[B,C,H,W]`|4维|
深度学习中的影像并不是以“图片”的形式进入模型，而是先转换成由像元数值组成的张量。
### 什么是张量形状
假设：

```
image.shape
```

输出：

```
torch.Size([4, 5, 512, 512])
```

这个张量有4个维度：

```
[4, 5, 512, 512]
 │  │    │    │
 B  C    H    W
```
含义如下：

|字母|含义|当前数值|
|---|---|---|
|`B`|Batch，一批有多少张影像|4|
|`C`|Channel，每张影像有多少个通道|5|
|`H`|Height，影像高度|512|
|`W`|Width，影像宽度|512|
所以：

```
[4, 5, 512, 512]
```

表示：

> 一批有4张影像；每张影像有5个通道；每个通道大小为512×512像元。

在项目中，这5个通道可能依次是：

```
0：R
1：G
2：B
3：NDRE
4：DSM
```
### 单张影像为什么没有B

单张五通道影像通常是：

```
[5, 512, 512]
```

也就是：

```
[C, H, W]
```

将多张影像交给 DataLoader 组成一个批次后，才会增加最前面的批次维度：

```
单张影像：[C, H, W]
                     ┐
单张影像：[C, H, W]  │
单张影像：[C, H, W]  ├──→ [B, C, H, W]
单张影像：[C, H, W]  │
                     ┘
```

例如：

```
单张：[5, 512, 512]
4张：[4, 5, 512, 512]
```

注意：==**`B=4`并不代表数据集只有4张影像，只表示模型这一次同时处理4张。**==
