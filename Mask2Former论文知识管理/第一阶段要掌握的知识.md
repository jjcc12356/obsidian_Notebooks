## 张量形态：
==**看到任意张量形态时，能够立刻说出每个数字代表什么，并判断它能不能送进Mask2Former**==
### python知识
- `变量.shape`：查看形状
- `变量.ndim`：查看维度数量
- Python下标从 `0` 开始
### 张量 Tensor
装着大量数字的多维容器
不同维度可以这样理解：

|类型|示例|维度数|
|---|---|---|
|一个数字|`5`|0维|
|一排数字|`[1, 2, 3]`|1维|
|一张数字表|`[[1,2],[3,4]]`|2维|
|一张多通道影像|`[C,H,W]`|3维|
|一批多通道影像|`[B,C,H,W]`|4维|
深度学习中的影像并不是以“图片”的形式进入模型，而是先转换成由像元数值组成的张量。
### 什么是张量形状
假设：

```
image.shape
```

输出：

```
torch.Size([4, 5, 512, 512])
```

这个张量有4个维度：

```
[4, 5, 512, 512]
 │  │    │    │
 B  C    H    W
```
含义如下：

|字母|含义|当前数值|
|---|---|---|
|`B`|Batch，一批有多少张影像|4|
|`C`|Channel，每张影像有多少个通道|5|
|`H`|Height，影像高度|512|
|`W`|Width，影像宽度|512|
所以：

```
[4, 5, 512, 512]
```

表示：

> 一批有4张影像；每张影像有5个通道；每个通道大小为512×512像元。

在项目中，这5个通道可能依次是：

```
0：R
1：G
2：B
3：NDRE
4：DSM
```
### 单张影像为什么没有B

单张五通道影像通常是：

```
[5, 512, 512]
```

也就是：

```
[C, H, W]
```

将多张影像交给 DataLoader 组成一个批次后，才会增加最前面的批次维度：

```
单张影像：[C, H, W]
                     ┐
单张影像：[C, H, W]  │
单张影像：[C, H, W]  ├──→ [B, C, H, W]
单张影像：[C, H, W]  │
                     ┘
```

例如：

```
单张：[5, 512, 512]
4张：[4, 5, 512, 512]
```

注意：==**`B=4`并不代表数据集只有4张影像，只表示模型这一次同时处理4张。**==
### 三通道与五通道有什么区别

原始RGB输入：

```
[B, 3, H, W]
```

改为多模态输入：

```
[B, 5, H, W]
```

例如：

```
# RGB
[4, 3, 512, 512]

# RGB + NDRE + DSM
[4, 5, 512, 512]
```

真正发生改变的是：

```
C：3 → 5
```

因此，模型第一层原来如果只接收3通道：

```
in_channels = 3
```

现在输入五通道张量，就会发生不匹配：

```
模型期待：[B, 3, H, W]
实际输入：[B, 5, H, W]
```

常见报错会类似：

```
expected input to have 3 channels, but got 5 channels
```

把第一层改成5只能说明“模型可以接收五通道”，不等于“模型已经学会有效利用NDRE和DSM”。这正是当前论文问题的核心。
### 怎样取出不同部分

假设：

```
x.shape == [4, 5, 512, 512]
```

### 1. 取第一张影像

```
x[0]
```

结果形状：

```
[5, 512, 512]
```

因为选定了一张影像，`B`维度消失了。

### 2. 取所有影像的RGB通道

```
x[:, 0:3, :, :]
```

结果形状：

```
[4, 3, 512, 512]
```

也可以简写成：

```
x[:, :3]
```

### 3. 取所有影像的NDRE

如果NDRE是第4个通道：

```
x[:, 3:4, :, :]
```

结果形状：

```
[4, 1, 512, 512]
```

这里用 `3:4`，而不直接使用 `3`，是为了保留通道维度。

对比：

```
x[:, 3].shape
# [4, 512, 512]

x[:, 3:4].shape
# [4, 1, 512, 512]
```

在卷积神经网络中，通常需要保留 `C` 这个维度，所以第二种更安全。
###  一个特别容易踩的坑

PyTorch模型通常使用：

```
[B, C, H, W]
```

但有些图像数据可能使用：

```
[B, H, W, C]
```

例如看到：

```
[4, 512, 512, 5]
```

这表示通道在最后，不能直接按一般PyTorch卷积的格式使用。

需要改变维度顺序：

```
x = x.permute(0, 3, 1, 2)
```

变化过程：

```
[4, 512, 512, 5]
       ↓
[4, 5, 512, 512]
```

现在先记住：

> PyTorch图像模型通常要求通道 `C` 位于第二个位置。
![[Pasted image 20260923105622.png]]
RGB   = [3, H, W]
NDRE  = [1, H, W]
DSM   = [1, H, W]
合并后 = [5, H, W]
批处理 = [B, 5, H, W]

如果使用PyTorch拼接，通常是在通道维拼接：

```
image = torch.cat([rgb, ndre, dsm], dim=0)
```

单张影像的 `dim=0` 是通道维。

如果已经有批次：

```
images = torch.cat([rgb, ndre, dsm], dim=1)
```

批次张量的 `dim=1` 才是通道维。

这是非常关键的区别：

|张量|形状|通道所在维度|
|---|---|---|
|单张影像|`[C,H,W]`|`dim=0`|
|一批影像|`[B,C,H,W]`|`dim=1`|

### 一、切片规则

基本形式：

```
x[start:stop]
```

需要注意：

> 包含 `start`，不包含 `stop`。

例如通道编号是：

```
0：R
1：G
2：B
3：NDRE
4：DSM
```

那么：

```
x[:, 0:3]
```

会取得通道：

```
0、1、2
```

也就是RGB，不包括编号3。

因此：

```
rgb  = x[:, 0:3]  # 也可以写成 x[:, :3]
ndre = x[:, 3:4]
dsm  = x[:, 4:5]
```

假设：

```
x.shape = [4, 5, 512, 512]
```

则：

```
rgb  → [4,3,512,512]
ndre → [4,1,512,512]
dsm  → [4,1,512,512]
```

---

### 二、使用 `torch.cat()`拼接通道

假设已有：

```
rgb.shape  == [4, 3, 512, 512]
ndre.shape == [4, 1, 512, 512]
dsm.shape  == [4, 1, 512, 512]
```

要把它们组成五通道输入：

```
x = torch.cat([rgb, ndre, dsm], dim=1)
```

结果：

```
x.shape == [4, 5, 512, 512]
```

为什么是 `dim=1`？

```
dim=0 → B，批次维
dim=1 → C，通道维
dim=2 → H，高度维
dim=3 → W，宽度维
```

我们要增加通道数量，所以沿 `dim=1` 拼接。

拼接过程：

```
[B,3,H,W]
[B,1,H,W]  --沿dim=1拼接--> [B,5,H,W]
[B,1,H,W]
```

`torch.cat()`是在已有维度上连接，不会凭空增加新的维度。

---

### 三、为什么有时需要 `unsqueeze()`

实际读取NDRE时，可能得到：

```
ndre.shape == [4, 512, 512]
```

它只有：

```
[B,H,W]
```

缺少通道维度 `C`，不能直接与：

```
rgb.shape == [4,3,512,512]
```

进行通道拼接。

需要在 `dim=1` 增加一个维度：

```
ndre = ndre.unsqueeze(1)
```

变化为：

```
原来：[4,512,512]
现在：[4,1,512,512]
```

DSM同理：

```
dsm = dsm.unsqueeze(1)
```

之后才能拼接：

```
x = torch.cat([rgb, ndre, dsm], dim=1)
```

得到：

```
[4,5,512,512]
```

---

### 四、单张影像与批次的区别

如果处理的是单张影像：

```
RGB ：[3,H,W]
NDRE：[1,H,W]
DSM ：[1,H,W]
```

通道维是 `dim=0`：

```
image = torch.cat([rgb, ndre, dsm], dim=0)
```

结果：

```
[5,H,W]
```

如果处理的是一批影像：

```
RGB ：[B,3,H,W]
NDRE：[B,1,H,W]
DSM ：[B,1,H,W]
```

通道维是 `dim=1`：

```
images = torch.cat([rgb, ndre, dsm], dim=1)
```

结果：

```
[B,5,H,W]
```

必须记住：

|数据状态|形状|通道维|拼接参数|
|---|---|---|---|
|单张影像|`[C,H,W]`|`dim=0`|`dim=0`|
|一批影像|`[B,C,H,W]`|`dim=1`|`dim=1`|
完成拼接后，不能只看有没有报错，至少要检查：

```
print(rgb.shape)
print(ndre.shape)
print(dsm.shape)
print(x.shape)
```

理想输出类似：

```
RGB:   [4,3,512,512]
NDRE:  [4,1,512,512]
DSM:   [4,1,512,512]
Input: [4,5,512,512]
```

如果得到：

```
[4,512,512,5]
```

说明通道位置不对。

如果得到：

```
[12,1,512,512]
```

说明很可能把批次维与通道维混淆了。
