## 张量形态：
==**看到任意张量形态时，能够立刻说出每个数字代表什么，并判断它能不能送进Mask2Former**==
### python知识
- `变量.shape`：查看形状
- `变量.ndim`：查看维度数量
- Python下标从 `0` 开始
### 张量 Tensor
装着大量数字的多维容器
不同维度可以这样理解：

|类型|示例|维度数|
|---|---|---|
|一个数字|`5`|0维|
|一排数字|`[1, 2, 3]`|1维|
|一张数字表|`[[1,2],[3,4]]`|2维|
|一张多通道影像|`[C,H,W]`|3维|
|一批多通道影像|`[B,C,H,W]`|4维|
深度学习中的影像并不是以“图片”的形式进入模型，而是先转换成由像元数值组成的张量。
### 什么是张量形状
假设：

```
image.shape
```

输出：

```
torch.Size([4, 5, 512, 512])
```

这个张量有4个维度：

```
[4, 5, 512, 512]
 │  │    │    │
 B  C    H    W
```
含义如下：

|字母|含义|当前数值|
|---|---|---|
|`B`|Batch，一批有多少张影像|4|
|`C`|Channel，每张影像有多少个通道|5|
|`H`|Height，影像高度|512|
|`W`|Width，影像宽度|512|
