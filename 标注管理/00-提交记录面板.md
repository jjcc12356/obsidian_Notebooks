# 图片标注提交记录面板

> [!important] 执行标准
> 每人每日目标 **10 张**，最低 **5 张**；每周至少 **5 个达标工作日**。标注结果须在当天 **10:00 前**提交，管理员在 **10:30 后**发送第二天任务。每次分配必须保存图片名称截图。

## 今日管理清单

- [ ] 10:00 前：检查所有人的当日提交
- [ ] 检查完成数量是否至少 5 张
- [ ] 核对样本名称清单与任务截图
- [ ] 登记迟交、少交、错标或缺图
- [ ] 10:30 后：发送所有人的次日任务
- [ ] 保存次日图片名称截图

## 最近 14 天记录

```dataview
TABLE WITHOUT ID
  file.link AS "记录",
  person AS "人员",
  date AS "日期",
  completed + "/" + target AS "完成量",
  choice(daily_pass, "✅ 日达标", "❌ 低于5张") AS "日标准",
  choice(target_pass, "✅", "—") AS "完成10张",
  choice(before_10, "✅ 准时", "⏰ 迟交") AS "提交",
  choice(screenshot_saved, "✅", "❌") AS "截图",
  choice(verified, "✅", "待复核") AS "复核"
FROM "标注管理/02-每日记录"
WHERE record_type = "annotation-daily" AND date >= date(today) - dur(14 days)
SORT date DESC, person ASC
```

## 待处理异常

```dataview
TABLE WITHOUT ID
  file.link AS "记录",
  person AS "人员",
  date AS "日期",
  completed AS "完成",
  choice(before_10, "", "迟交 ") + choice(screenshot_saved, "", "缺截图 ") + choice(daily_pass, "", "未达最低标准 ") + choice(verified, "", "待复核") AS "问题"
FROM "标注管理/02-每日记录"
WHERE record_type = "annotation-daily"
  AND (!daily_pass OR !before_10 OR !screenshot_saved OR !verified)
SORT date DESC, person ASC
```

## 本周个人汇总

```dataview
TABLE WITHOUT ID
  key AS "人员",
  length(rows) AS "记录天数",
  length(filter(rows, (r) => r.daily_pass)) AS "达标天数",
  sum(rows.completed) AS "完成总数",
  round(average(rows.completed), 1) AS "日均",
  choice(length(filter(rows, (r) => r.daily_pass)) >= 5, "✅ 周达标", "❌ 不足5天") AS "周结果"
FROM "标注管理/02-每日记录"
WHERE record_type = "annotation-daily" AND week = dateformat(date(today), "kkkk-'W'WW")
GROUP BY person
SORT key ASC
```
