## 【今天新学】

今天真正的新思维只有两个：

**科研图中的“观察单位”**
>科研图中的“观察单位”（unit of observation）指：**图中每个独立数据点/独立观测所对应的最小实体**。它决定了你的 nn 到底是多少、误差线怎么算、用什么统计方法，以及结论能推断到什么层级。

>一句话：**图里每个点代表谁？是每只小鼠、每个患者、每个独立实验，还是每个视野/孔/细胞？**

> 常见层级与例子

- 动物实验：处理随机分配给小鼠 → 观察单位通常是**每只小鼠**。同一只鼠测 3 次，是技术重复，不是 n=3n=3。
    
- 细胞实验：处理加在独立培养皿/孔 → 观察单位可能是**每个独立皿/孔/独立实验批次**。同一皿拍 5 个视野，这 5 个视野通常是亚样本，不是 5 个独立观察。
    
- 临床研究：观察单位通常是**每位患者**。同一患者多次随访，属于重复测量，不能当多个独立患者。
    
- 嵌套结构：患者 → 样本 → 切片 → 视野 → 细胞。越往下的层级通常越不独立，不能简单把最细层级的数量当 nn。
    

> 为什么重要

如果把非独立测量当成独立观察，就会出现**伪重复**，人为增大 nn，使 pp 值偏小、结论假阳性。审稿人常问：  
**“What is nn? What is the unit of observation?”**  
就是在确认你的统计独立性。

> 在科研图中如何体现

- 散点图：每个点最好代表一个独立观察单位。
    
- 柱状图：柱高通常是均值/汇总值，本身不是观察单位；应配合散点或箱线图展示分布。
    
- 误差线：必须注明是 SD、SEM 还是 95% CI，并说明 nn 是什么。
    
- 连线图：同一观察单位的前后测量可以连线，表示配对/重复测量。
    
- 图注模板：  
    “Each point represents one independent biological replicate (one mouse). Bars show mean; error bars show SEM; n=6n=6 mice per group.”  
    或  
    “Each point represents one independent experiment (n=4n=4); technical replicates were averaged before plotting.”
    

> 判断观察单位的检查清单

1. 处理/干预随机分配在哪个层级？
    
2. 哪个层级真正独立、可重复？
    
3. 图中每个点、每根柱、每个误差线代表什么？
    
4. nn 是观察单位数量，还是测量次数？
    
5. 是否有嵌套、重复测量、配对设计？
    
6. 统计方法是否匹配，如混合效应模型、配对检验、GEE 等？
    

总之：**科研图中的观察单位不是“你测了多少个数”，而是“这些数来自多少个彼此独立的实体”。** 图注里必须写清楚，否则读者和审稿人无法判断你的 nn 和统计是否可靠。
以及：

**“原始变量”和“模型参数”不是同一个东西。**

这其实比会写一行 `scatter()` 更重要。
